## 1. Executive Summary

Hive AI is an enterprise cloud intelligence provider offering proprietary computer vision and natural language processing models for automated content moderation. Their flagship detection offering centers on synthetic media identification:
- **AI-Generated Image Detection** (including generator family attribution)
- **AI-Generated Video Detection** (temporal frame demuxing and multi-frame consistency)
- **Visual Deepfake Detection** (facial reenactment and face-swap boundary analysis)

All Hive AI models are hosted exclusively in Hive's proprietary cloud infrastructure. No offline binaries, on-premise containers, or downloadable weights are made publicly available. Consequently, any direct integration with Hive AI requires external network transmission, paid API credentials, and client-side consent gating.

## 2. Publicly Verifiable Technical Features

### 2.1 AI-Generated Image Detection
- **Input Pipeline:** Accepts raster image formats (`image/jpeg`, `image/png`, `image/webp`). Preprocessing normalizes spatial resolutions and strips ambient EXIF metadata before tensor ingestion.
- **Inference Mechanism:** Inferred to employ deep convolutional (CNN) and hierarchical Vision Transformer (ViT) backbones trained on massive corpuses of authentic photographs paired with synthetic generations from diffusion and autoregressive models.
- **Classification Output:** Returns two primary top-level classes:
  - `ai_generated` (normalized float between `0.000` and `1.000`)
  - `not_ai_generated` (normalized float between `0.000` and `1.000`)
- **Generator Attribution Subclasses:** Attributes the likely generative architecture responsible for synthesis:
  - `midjourney` (versions 4, 5, 5.2, 6)
  - `stable_diffusion` (SD 1.5, SD 2.1, SDXL, SD 3)
  - `dall_e` (DALL-E 2, DALL-E 3)
  - `flux` (Flux.1 Schnell / Dev)
  - `imagen` (Google Imagen)
  - `firefly` (Adobe Firefly)
- **Confidence Calibration:** Employs temperature-scaled softmax outputs. Hive documentation explicitly notes that low-resolution imagery (<256x256 px), heavy re-compression, or subtle post-processing edits can skew model confidence.

### 2.2 AI-Generated Video Detection
- **Container Demuxing:** Ingests container streams including MP4, MOV, WebM, and AVI. Max upload file size is typically 50 MB on standard sync tiers and up to 500 MB on async batch pipelines.
- **Temporal Keyframe Extraction:** Demuxes video streams into discrete frames at uniform temporal intervals (default: 1.0 second or 0.5 second intervals).
- **Frame-by-Frame Inference:** Each extracted keyframe is passed through the visual generation detection head, generating an individual timestamped confidence vector.
- **Temporal Consistency Aggregation:** Evaluates cross-frame variance. Synthetic videos generated by models such as Sora, Runway Gen-2/3, Pika, or Stable Video Diffusion typically display high-frequency inter-frame jitter or morphing artifacts. Hive aggregates individual frame scores to produce a video-level verdict.
- **Limitations:** Highly compressed social media videos, low frame rates (<15 fps), or rapid camera cuts can induce false-positive spikes.

### 2.3 Visual Deepfake & Face-Swap Forensics
- **Facial Region Isolation:** Automatically detects human faces using bounding boxes `[x1, y1, x2, y2]`.
- **Artifact Analysis:** Focuses on boundary blending discontinuities, eye reflection asymmetry, unnatural eyelid blinking frequencies, and skin-tone mismatches between the facial crop and surrounding neck/hair regions.
- **Output:** Categorizes facial crops as `is_deepfake` vs `not_deepfake` with spatial bounding box overlays.

## 3. Technical API Specification & Data Contracts

### 3.1 Endpoints & Communication Protocols
Hive AI provides synchronous and asynchronous REST endpoints:
- **Sync Ingest:** `POST https://api.thehive.ai/api/v2/task/sync`
- **Async Ingest:** `POST https://api.thehive.ai/api/v2/task/async`
- **Poll Status:** `GET https://api.thehive.ai/api/v2/task/{task_id}`
- **Authentication:** `Authorization: token <HIVE_API_KEY>`

### 3.2 Request Payloads
1. **Direct Binary Upload (`multipart/form-data`):**
   ```http
   POST /api/v2/task/sync HTTP/1.1
   Host: api.thehive.ai
   Authorization: token hiv_live_sec_examplekey1234
   Content-Type: multipart/form-data; boundary=----Boundary123

   ------Boundary123
   Content-Disposition: form-data; name="media"; filename="evidence.jpg"
   Content-Type: image/jpeg

   <BINARY_IMAGE_BYTES>
   ------Boundary123--
   ```

2. **Hosted URL Ingestion (`application/json`):**
